## Original Spark and Infinity Spark

Recovered facts:

- Two named projects existed: **Original Spark** and **Infinity Spark**.
- The intended target repository was `infinity-spark`.
- Spark-published comments/pages were supposed to be committed into that repository.
- Generated pages used this structure:

```text
pages/<slug>/index.html
pages/<slug>/meta.json
```

- One `.github/workflows/pages.yml` workflow was intended to publish the root index and generated pages.
- The site was intentionally static: no npm, installs, bundler, or build step.
- A root `index.html` was required.
- Automatic commits required authenticated GitHub API access.
